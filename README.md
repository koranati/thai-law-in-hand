# กฎหมายในมือ (Thai Law in Hand)

เว็บแอปข้อมูลกฎหมายไทยสำหรับประชาชน เน้นค้นง่าย อ่านง่าย และรองรับมือถือ

## v1
- Responsive mobile/desktop
- Light / Dark mode
- หมวดกฎหมายทั่วไป แรงงาน บ้านและคอนโด รัฐธรรมนูญ และอื่น ๆ
- Search prototype
- AI legal issue triage prototype (rule-based; ยังไม่ใช่ generative AI)
- Legal-information disclaimer

## หลักการด้านความน่าเชื่อถือ
ก่อนนำข้อมูลกฎหมายจริงเข้าสู่ production ต้องตรวจสอบกับตัวบทฉบับปัจจุบันจากแหล่งทางการ เช่น ราชกิจจานุเบกษา สำนักงานคณะกรรมการกฤษฎีกา และหน่วยงานรัฐเจ้าของกฎหมาย และควรเก็บ source URL / วันที่ตรวจสอบ / สถานะการแก้ไขของกฎหมายทุกฉบับ

## Roadmap
1. เพิ่มฐานข้อมูลกฎหมายและมาตราที่ตรวจสอบแหล่งอ้างอิงแล้ว
2. เพิ่มหน้ารายละเอียดมาตราและ citation
3. เชื่อม AI backend แบบ source-grounded/RAG
4. เพิ่ม safety: ไม่ฟันธงผลคดี, แจ้งข้อจำกัด, แนะนำช่องทางหน่วยงาน/ผู้เชี่ยวชาญเมื่อเหมาะสม
5. เพิ่ม PWA และ accessibility

> โครงการนี้ให้ข้อมูลกฎหมายเบื้องต้น ไม่ใช่คำปรึกษาทางกฎหมายเฉพาะคดี
